# Read and search the docs

Each macro shows the API's title, version and spec format, where the spec came from, and when it was loaded.

- **Refresh** reloads the spec from its source, skipping the cache (signed-in users).
- **Changes** compares the spec with an earlier version. See [Compare versions](compare.md).
- **Download** saves the spec as JSON, with split files merged into one.
- **Full screen** fills your screen with the docs; press Esc to leave.

Expand an operation to see its parameters, request body, responses and schemas. With code samples on, each operation has ready-to-copy cURL, JavaScript, Python, Go, Java and C# snippets built from the spec; your chosen language sticks as you move between operations.

Endpoints show up in Confluence search, so searching for a path or summary finds the page.

Guests and anonymous visitors can read docs on spaces open to them. They can't use Try it out or Changes.

When a page is exported to PDF or Word, the macro becomes a table of endpoints.
