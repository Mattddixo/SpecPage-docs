# API docs pages and the API catalog

Every space gets an **API docs** page listing each page in the space that has a SpecPage macro: the API's title and version, spec format, number of operations, the page, and where the spec comes from. Find it in the space's sidebar under apps.

The **API catalog** in Confluence's **Apps** menu lists the same across the whole site, with a column for the space.

Both have a filter box that searches API names, pages, spaces and sources.

Readers only see pages they're allowed to view. A macro appears once its page has been viewed after the macro was saved, and drops off when the macro is removed from the page.
